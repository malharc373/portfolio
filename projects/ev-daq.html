Data Acquisition System for a Formula Student EV

Telemetry and logging for an electric race car: CAN, onboard SD logging, Bluetooth live data and Python post-run tools.

  • STM32 Blue Pill
  • Arduino
  • Raspberry Pi
  • RaceCapture
  • Lua
  • CAN
  • ADC
  • HC-05
  • Python
Channels
Analog + digital
Link
CAN, Bluetooth
Storage
Timestamped SD logs
Tools
Python, shell

What it does

  • Collects real-time voltage, current, RPM, temperature, brake-pressure and suspension data over analog and digital channels.
  • Streams live telemetry over Bluetooth and writes timestamped logs to onboard SD.
  • Includes a driver interface and CAN-based communication between modules.
  • Python and shell tools automate log parsing, visualisation and performance mapping after each run.

Context

Designed for the team's Formula Student electric car. See the racing page for the wider team work.
