Pipeline

  • Ingests the open dataset over HTTP into a typed, validated DuckDB warehouse with seven data-quality checks.
  • SQL analytics for KPIs, QoQ/YoY growth, concentration (HHI) and robust anomaly flags.
  • Leakage-free forecasting with naive baselines, ridge and gradient boosting, scored by walk-forward backtest, with calibrated 10–90% prediction intervals.
  • Isolation Forest anomaly detection and K-Means state archetypes.
  • FastAPI service and a tabbed Streamlit dashboard with an India choropleth; CI and weekly scheduled re-ingestion via GitHub Actions.

Framing

Figures are aggregated and anonymised. Insights are framed as areas to investigate, never as claims about individual users, merchants or fraud.
