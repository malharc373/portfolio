Scheduled — Natural-Language Calendar

macOS menu-bar app that turns plain English into Apple Calendar events and Reminders that sync across devices.

  • Swift
  • SwiftUI
  • AppKit
  • EventKit
  • OpenRouter
View on GitHub ↗
Platform
macOS 14+
Sync
iCloud via EventKit
Hotkey
⌘⌃J
Also
CLI for Raycast / cron

How it works

Type something like “lecture tomorrow at 2pm for 2 hours” or “move my dentist appointment to 4pm”. An LLM returns structured JSON, which is written to the system EventKit store, the same store iCloud already syncs. No custom backend and no polling.

Details

  • Native alarms through EKAlarm on iPhone, iPad, Mac and Watch.
  • Current date, time and timezone are sent to the model as ground truth for accurate relative dates.
  • Builds with Command Line Tools only; the same binary doubles as a CLI.
