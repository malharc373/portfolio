IoT-IDS — Edge Intrusion Detection

A small flow-based model that detects 9 attack types on constrained hardware, plus a cross-dataset transfer study over 11 public IDS datasets.

Two deliberately separate halves

1. Live edge IDS/IPS. A streaming sensor that sniffs traffic, aggregates packets into bidirectional flows, classifies each flow with a 22-feature model, and reports aggregated per-source incidents. The same model compiles to a dependency-free C header (~43 KB) for microcontrollers, inference only so far.

2. SFAF cross-dataset study. A semantic feature-alignment framework over eleven public IDS datasets (CICIDS2017, UNSW-NB15, TON-IoT, Bot-IoT and others) aligned into one feature space to measure how well flow behaviour transfers between labs, devices and tools. It surfaced severe domain shift.

Being straight about limits

  • Active blocking is deliberately disabled on real networks because the first live baseline produced unsafe false positives; the response module runs dry-run.
  • An earlier cross-dataset diagonal turned out to be resubstitution (train and test were the same rows). The corrected held-out protocol is implemented, and headline numbers are withheld until the full study is rerun.
  • The Raspberry Pi 4 target and the end-to-end microcontroller path are not yet validated.
