AarthFit — MSME Financial Fitness Platform

Multi-tenant SaaS that turns a daily WhatsApp question into a CFO Score for small-business owners.

The idea

Owners answer one question a day over WhatsApp. Answers roll up into a CFO Score across cashflow, compliance, profitability, balance sheet and governance, benchmarked by business type and revenue tier, and tracked on a self-serve dashboard.

What I built

  • Data architecture, REST API and relational schema: a Fastify + TypeScript API in a pnpm monorepo with shared zod schemas, Knex migrations and repository functions with audit logging.
  • Redis-backed OTP and JWT authentication with role-based access control.
  • Razorpay payments with webhook signature verification, and the Meta WhatsApp Cloud API with template linting.
  • A role-based admin portal (deals, companies, staff, accountant workspace) and a super-admin platform-metrics dashboard across tenants, using indexed, time-scoped aggregate queries behind a short Redis cache.
  • CFO Score PDF reports generated with pdfkit and delivered over AWS SES; background jobs on in-process cron.
  • Integration tests with Vitest against real Postgres and Redis.

Note

This is client work, so the repository is private.
